# Technical Manual

The Technical Manual is for **developers and IT teams** who install, configure, host and extend Orchard Core: creating applications, writing modules and themes, configuring and deploying sites, and using the APIs. If you work in the admin screens of a site and don't write code, the [User Manual](../user-manual/index.md) is for you.

## Which one do I need?

| I want to... | Start with |
| --- | --- |
| Try Orchard Core without writing code | [Test drive Orchard Core](../getting-started/test-drive-orchard-core.md) |
| Create a website with Orchard Core CMS | [Create a CMS web application](../getting-started/README.md), then [Create a website](../guides/create-cms-application/README.md) |
| Build an application on the framework, without the CMS | [Create a modular application](../guides/create-modular-application-mvc/README.md) |
| Use Orchard Core as a headless or decoupled CMS | [Create a Decoupled CMS site](../guides/decoupled-cms/README.md) |
| Write a module or a theme | [Create a Custom Module](../guides/create-install-custom-module/README.md), [Create a Theme](../getting-started/theme.md) |
| Configure a site with `appsettings.json` or environment variables | [Configuration](../topics/configuration/README.md) |
| Look up a module, its settings or its recipe steps | [Module reference](../reference/README.md) |
| Run Orchard Core in containers | [Using Docker](../topics/docker/README.md) |
| Let an AI coding assistant help you | [AI Quick Start](../getting-started/ai-quick-start.md) |

!!! tip "Pages for both audiences"
    Many module pages start with a **Using this from the admin screens?** box. It links to the User Manual pages that explain the same feature step by step, which is handy when you hand a site over to its editors.
