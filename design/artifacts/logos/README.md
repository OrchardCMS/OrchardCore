# Logo assets

## Pomi

[`pomi/`](pomi/README.md) contains the supplied terminal-and-leaf logo asset set,
copied from `outputs/pomi-logo`: SVGs, transparent PNGs, small icon exports,
original images, a preview, and the source and export script.

Use the light and dark SVG logos for documentation. Their lettering is outlined
and they require no font downloads. The published copies of `svg/` and `png/`
live in [`src/docs/reference/branding/assets/logo/pomi/`](../../../src/docs/reference/branding/assets/logo/pomi/).
Update both copies together when replacing the master assets.
